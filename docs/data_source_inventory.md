# Budget Data Source Inventory

## Overview
This document identifies the official, public sources for Tamil Nadu state budget data required for Phase 1 (Budget & Scheme Analyzer) of the CivicLens TN project. As per project constraints, only official government sources are used; third-party aggregated datasets are excluded.

## PRIMARY SOURCE: Tamil Nadu Budget Portal

*   **Source Name:** Tamil Nadu Finance Department - Budget Portal
*   **Exact Dataset/Document Name:** Detailed Demands for Grants (DDG)
*   **Official URL:** `http://www.tnbudget.tn.gov.in/` (often redirects to the Finance Department site `https://financedept.tn.gov.in/`)
*   **Financial Years Covered:** Multiple consecutive historical years up to the current financial year (typically archived from at least 2011-12 onwards).
*   **File Format:** PDF
*   **Download/Access Method:** Direct download via HTTP from the portal's "Demands" section.
*   **Publication Date/Year:** Published annually (usually in February/March when the budget is presented to the legislative assembly).

### Coverage Against Requirements

| Field | Status in Primary Source | Notes |
| :--- | :--- | :--- |
| **department name** | Available | Title of the specific Demand document. |
| **department identifier** | Available | The "Demand Number" (e.g., Demand 43 for School Education). |
| **scheme name** | Available | Detailed text under Minor/Sub-Heads. |
| **scheme identifier** | Available | The Head of Account code (e.g., 2202-01-101-AA). |
| **sector/category** | Available | Grouped by Major Head codes which map to sectors. |
| **financial year** | Available | Clearly stated in column headers (e.g., 2024-2025). |
| **budget allocation** | Available | Published as "Budget Estimate" (BE). |
| **revised allocation** | Available | Published as "Revised Estimate" (RE) for the preceding year. |
| **actual expenditure** | Available | Published as "Accounts" or "Actuals" (typically T-2 years). |
| **scheme description/objective** | **Unavailable** | The DDG contains only the financial nomenclature, not qualitative objectives. |
| **source document** | Available | Identifiable via the PDF filename/title. |
| **source URL/reference** | Available | The direct link to the PDF on the portal. |
| **page/section reference** | Available | Can be generated by tracking the page number during data extraction. |

### Notes and Limitations
*   **Data Format:** The data is provided exclusively in PDF format. This will necessitate a complex PDF table extraction pipeline. No machine-readable CSVs of the Detailed Demands for Grants are officially published.
*   **Bilingual Content:** The PDFs typically contain both Tamil and English text intermingled. Extraction logic must be able to handle or cleanly separate the languages.

## SECONDARY/OPTIONAL SOURCES

These sources are only to be used to fill specific, documented gaps in the Primary Source.

### 1. Department Policy Notes
*   **Required for:** Filling the gap for the **scheme description/objective** field.
*   **Exact Dataset/Document Name:** Department Policy Notes (published per department per year).
*   **Official URL:** `http://www.tnbudget.tn.gov.in/` (Available under the "Policy Notes" section).
*   **File Format:** PDF
*   **Download/Access Method:** Direct download from the budget portal.
*   **Notes:** Provides the qualitative context missing from the financial DDGs. Will require text matching to link descriptions back to the financial line items.

### 2. Tamil Nadu Open Data Portal (tn.data.gov.in)
*   **Required for:** Not strictly required, but serves as an optional fallback for macro-level aggregations if detailed parsing fails.
*   **Exact Dataset/Document Name:** Budget at a Glance (varies by availability).
*   **Official URL:** `https://tn.data.gov.in/`
*   **File Format:** CSV / JSON
*   **Notes:** Rarely contains granular scheme-by-scheme data, which is why it cannot serve as the primary source. Only useful for high-level cross-checks.
