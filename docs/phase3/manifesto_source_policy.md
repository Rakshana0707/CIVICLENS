# Manifesto Source Policy

Manifesto information must **NOT** be collected by blindly scraping search results or political commentary websites. Every manifesto record must contain its source tier to track the reliability of the source.

## Source Hierarchy

### Tier 1 — Primary source
The political party's official website or official manifesto document. This is the gold standard for manifesto collection.

### Tier 2 — Official/public institutional source
Election-related official or public institutional archives where the manifesto itself is available (e.g., Election Commission libraries).

### Tier 3 — Reputable archive or public dataset
Use this when the original party document is unavailable, inaccessible, or no longer publicly hosted. Examples include open data platforms and reputable political science repositories.

### Tier 4 — Reputable news/research archive
Use only to locate or cross-check the original manifesto. A news article summarizing a manifesto is **not** a manifesto document.

### Tier 5 — Other sources
Use only for discovery and never as the sole authoritative source when stronger evidence exists. Unofficial blogs, forums, or unverified uploads fall into this category.

## Enforcement
If automated retrieval is not permitted or technically available for higher tiers, the system must record the source URL and metadata, and allow manual acquisition of the document instead, preserving the Tier score.
